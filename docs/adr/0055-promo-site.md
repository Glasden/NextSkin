# ADR-0055 宣传站：`apps/site` 一页放一个介绍视频里的场景，滚动蓄力翻页、播完自动翻；手机和"减少动态效果"只给静帧和文字；和文档站一样部署在 Workers 上

- 状态：已采纳
- 日期：2026-10-22
- 补充 ADR-0054：落地"以后的宣传站放在 `nextskin.org`"

## 背景

ADR-0054 给宣传站留了位置：根域名 `nextskin.org`，照文档站的形态部署。

项目已经有一支 82 秒的介绍视频，是一个 Remotion 工程，不在仓库里。视频有 20 个场景，画面上的数据都用仓库的代码现算：3D 出图、像素 hash、PNG 的块、契约用例、ADR 份数。场景只按当前时刻算画面，对 Remotion 的依赖只有取帧号、静态资源路径、等字体加载这几处。

视频的约束：

- 配乐是商业授权的曲子，授权只覆盖视频平台；
- 动效按配乐的 126 BPM 卡点：拍头上阴影加大、每拍循环点亮、四记重音换主题；
- 画面按 1280×720 排版，小字只有 12px，缩到手机宽度大约是 0.27 倍，看不清；
- Remotion 不是开源许可：个人和不超过 3 人的公司免费，其他要买许可。

## 决定

### 代码在本仓库，场景从视频分叉

- 宣传站是 `apps/site`（包名 `@nextskin/site`），Astro 静态站，Astro 和文档站同一个版本。页面骨架和文字在构建时生成 HTML，场景是 React 组件，只在桌面上水合。
- 场景从视频工程复制过来改写：去掉 Remotion、配乐和卡点的动效，颜色改用 `theme.css` 的 token 类（不变量 10），标志、展台用 `packages/ui` 的组件。
- 视频工程留在仓库外，以后不和网站同步：网站去掉了卡点、合并了几场、改了顺序，两边已经不是同一份画面。配乐和 Remotion 都不进仓库。
- 画面上的数据照旧在构建时由仓库代码算出来（`apps/site/scripts`）：
  - 3D 出图和光栅化的过程用 `packages/skin`；
  - 几种编码的文件 hash 和像素 hash、PNG 安检和解压炸弹用 `packages/domain`；
  - 插件查询的重建用核心的 `sanitizePluginQuery`；
  - 契约用例的标题和数量、ADR 份数、迁移数直接读仓库。

  代码变了，下一次构建画面就跟着变。

### 桌面：一页一个场景，蓄力翻页

页面顺序：前半给服主和玩家，后半讲工程，中间用一页分界。

| 页 | 内容 |
|---|---|
| 1 | 首屏：标志逐格拼出、站名，三个入口，底下一个跳动的箭头引导往下翻（点了也翻） |
| 2 | 一条命令，零原生依赖，一个 ZIP 跑六个平台 |
| 3 | 和 BS 同一套协议 |
| 4 | 从 BS 迁移：一个事务，全有或全无 |
| 5 | 四种数据库 |
| 6 | `nextskin doctor` 自检 |
| 7 | 玩家能用的功能，整页依次换四套主题 |
| — | 分界：以上是看得见的部分，接下来是看不见的 |
| 8 | 材质按像素存，不按文件存 |
| 9 | 上传的 PNG 先过安检 |
| 10 | 契约回放：几条对比同屏 |
| 11 | 皮肤图用纯 TS 软件光栅化 |
| 12 | 插件热更新：整个进程换一代 |
| 13 | 插件的查询由核心重建 |
| 14 | 事件和业务写入同一个事务提交 |
| 15 | 尾页：数字和入口 |

播放：

- 16:9 的画面固定在视口中央，按 1280×720 排版，缩放到铺满视口（除去下方的控制条）。像素字体和出图只在整数倍时锐利（DESIGN.md §4、§5），所以整数倍和铺满只差不到一成时取整数倍。起初一律取整数倍，可 1080p 的显示器放不下 2 倍，画面只有 1280×720，占不到视口的三分之二；小数倍时像素字体的笔画粗细差一个设备像素，远看察觉不到。
- 每页的动画按自己的时钟播放。播完以后按画面的文字量停留几秒，再自动翻到下一页。

翻页：

- 页面接管滚轮。滚动给画面下方的蓄力条充能，满了就翻页；停手后蓄力条慢慢回落。翻页以后，这一下滑动剩下的惯性事件全部丢掉，免得触控板一次滑动连翻两页。
- 停留期间，蓄力条自己慢慢涨满，当自动翻页的倒计时用。动画没播完时也能蓄力，等于跳过。
- 键盘：↓、PageDown、空格翻到下一页，↑、PageUp 回上一页，Home、End 到首尾。
- 翻页时，下一页从下方分 4 格推上来，不淡入淡出（DESIGN.md 的阶跃动效）。

哪些页不自动翻：

- 首屏不自动翻，等第一次操作；
- 看过的页不再自动翻，回到看过的页直接显示最后一帧，往回看时不会被推走；
- 尾页不自动翻。

其他：

- 有暂停按钮，切到别的标签页时也会暂停（WCAG 2.2.2，自动播放的内容要能暂停）。
- 每页一个锚点，用 `replaceState` 更新，不往浏览器历史里塞记录；打开带锚点的地址直接到那一页。

### 手机和"减少动态效果"：静帧加文字

- 窄屏、触屏、开了"减少动态效果"的设备上，播放器不水合（Astro 的 `client:media`）。页面正常滚动，每一页是场景的最后一帧加一段文字。
- 静帧就是构建时把场景渲染到最后一刻的 HTML，按宽度缩放，不另出图片：文字能选中，构建时也不用跑浏览器。静帧上的小字在手机上照样看不清，所以静帧只当插图，信息靠下面的文字。
- 每页的文字也是读屏软件和搜索引擎读到的内容。桌面上，当前页的文字以读屏文本的形式放在画面里。

### 入口

首屏和尾页各放一组入口：

- 文档站；
- 一个已经迁到 NextSkin 的社区站点：入口直接链到它的皮肤库，文案写"看一个在用的站点"。它不是演示站，访客注册以后能做的事由那个站点自己决定；
- GitHub。

### 部署

- Worker `nextskin-site` 只有静态资源，没有脚本；关掉 `workers.dev` 地址和预览地址。
- 路由 `nextskin.org/*`，不用自定义域，理由同 ADR-0054。
- 根域名不开代理，解析到 `edge.nextskin.org` 那组优选 IP：
  - 优先用 CNAME 指向 `edge`，Cloudflare 会在根域名上把它拉平成 A 记录，换 IP 仍然只改 `edge` 一处；
  - 根域名上有邮件的 MX 和 TXT 记录。Cloudflare 拉平的 CNAME 能和它们共存（2026-10-22 建记录时确认）；以后换了 DNS 服务商、共存不了时，就直接填同样的 A 记录。
- `www` 先不做。
- 部署时机同文档站：维护者发布正式版的 Release 以后，在那个标签上构建并部署，而且只部署已发布的正式版里最新的那一个。PR 和推送上，改了相关的文件时只构建、不部署。
- 凭据用文档站的 `docs` environment：那个令牌的权限（这个账号的 Workers 脚本、`nextskin.org` 的 Workers 路由）已经够用。
- 资源同源，理由同 ADR-0054：字体随站点发布，不接第三方统计和公共 CDN。

## 后果

- `pnpm install` 多装 `@astrojs/react`。Tailwind 和 React 仓库里本来就有。
- 场景和视频分叉。以后重做视频，从网站的场景出发更合适。
- 宣传站要等包含 `apps/site` 的第一个正式版发布后才会上线。在那之前想上线，只能手动 `wrangler deploy`。
- 页面接管了滚轮，和普通网页的滚动习惯不同。触控板的惯性只能按事件之间的间隔判断，偶尔会多吞或少吞一下。

## 考虑过的其他方案

- **嵌入视频成片**：配乐的授权不覆盖网站；手机上看不清；2K 版 10 MB。
- **用 `@remotion/player` 直接嵌入视频的合成**：网站运行时依赖 Remotion，它的许可不是开源许可。
- **画面严格跟着滚动走**（停下就停、往回滚就倒放）：十几页要滚很长，读者累。
- **和文档站合成一个 Astro 项目**：Starlight 的页面布局和全屏翻页合不到一起，两边的依赖和样式也不同。
- **手机端用构建时的截图**：构建时要跑浏览器；HTML 静帧更清楚，文字也能选中。
