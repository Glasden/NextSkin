玩家用站点账号登录，一个账号可以管理多个 Minecraft 角色（玩家名），每个角色一套皮肤和披风。

## 上传材质

上传入口在角色页面。材质会先做格式检查和像素处理，再生成头像、3D 人物和披风正背面图。

## 外置登录与皮肤 Mod

启动器里加认证服务器、客户端装 CustomSkinLoader 之类的皮肤 Mod，具体地址和配置见[在游戏里用](/players/client/)。

站点地址由服主提供；账号、角色和材质都在站点上管理。
